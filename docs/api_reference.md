# 家電操作クラス API リファレンス

## 概要
このクラスは、家電の制御を行うための共通インターフェースを提供します。異なる種類の家電でも統一的な操作が可能です。

---

## クラス名: `DeviceController`

### コンストラクタ
**`DeviceController(config: dict)`**

- **説明**: 家電コントローラーのインスタンスを初期化します。
- **引数**:
  - `config` (*dict*): 家電の設定情報。例: デバイスのIDや種類。
- **例**:
  ```python
  controller = DeviceController({"device_id": "light001", "type": "light"})
メソッド
turn_on()
説明: デバイスの電源をオンにします。
引数: なし
返り値: なし
例:
python
コードをコピーする
controller.turn_on()
turn_off()
説明: デバイスの電源をオフにします。
引数: なし
返り値: なし
例:

set_temperature(temp: float)
説明: エアコンの温度を設定します。
引数:
temp (float): 設定温度（摂氏）。
返り値: なし
例:
python
コードをコピーする

エラーコード
コード	説明

注意事項
このクラスは内部でデバイスごとのドライバを使用しますが、利用者は意識する必要はありません。
サポートされていないデバイスの種類を指定した場合、例外が発生します。
